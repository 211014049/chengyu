笑里藏刀

xiào lǐ cáng dāo

战争成语 首字母 X
广告位 · 顶部

释义

形容对人外表和气，却阴险毒辣。

出处 / 典故

出自《旧唐书·李义府传》：「义府貌状温恭，与人语必嬉怡微笑，而褊忌阴贼……故时人言义府笑中有刀。」形容表面和善、内心狠毒的人。

例句 / 造句

  • 职场上要提防笑里藏刀的人，表面热情背后使坏。
  • 他笑里藏刀，嘴上夸你方案好，转头就去告状。
  • 笑里藏刀的伪善，比真刀真枪更可怕。

近义词

口蜜腹剑佛口蛇心两面三刀

反义词

表里如一心直口快光明磊落

成语接龙：「刀」字开头

暂无以「刀」开头的收录成语
