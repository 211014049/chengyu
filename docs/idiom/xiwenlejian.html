喜闻乐见

xǐ wén lè jiàn

情感成语 首字母 X
广告位 · 顶部

释义

喜欢听，乐意看。指很受欢迎。

出处 / 典故

出自明代王守仁《王文成公全书》相关用语的演化，形容群众喜欢听、乐意看的事物，常用于文艺作品受欢迎。

例句 / 造句

  • 这部方言喜剧深受本地观众喜闻乐见。
  • 用群众喜闻乐见的方式宣传政策，效果更好。
  • 短视频科普成为年轻人喜闻乐见的学习方式。

近义词

脍炙人口雅俗共赏家喻户晓

反义词

无人问津枯燥乏味面目可憎

成语接龙：「见」字开头
