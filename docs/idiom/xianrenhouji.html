先人后己

xiān rén hòu jǐ

品德成语 首字母 X
广告位 · 顶部

释义

首先考虑别人，然后想到自己。

出处 / 典故

出自《礼记·坊记》：「君子贵人而贱己，先人而后己。」指把别人的利益放在自己前面。

例句 / 造句

  • 分房时他先人后己，把好楼层让给了老同事。
  • 先人后己的班长，总是最后一个吃饭。
  • 灾难面前，先人后己的选择彰显人性光辉。

近义词

舍己为人舍己从人公而忘私

反义词

损人利己自私自利先己后人

成语接龙：「己」字开头

暂无以「己」开头的收录成语
