笑逐颜开

xiào zhú yán kāi

情感成语 首字母 X
广告位 · 顶部

释义

笑得使面容舒展开来。形容满脸笑容，十分高兴的样子。

出处 / 典故

出自明代凌濛初《初刻拍案惊奇》：「母亲方才转忧为喜，笑逐颜开。」逐，驱使；颜，面容。形容高兴得满脸笑容。

例句 / 造句

  • 听到孩子平安出生，产房外的爸爸笑逐颜开。
  • 困扰多日的难题解决了，他笑逐颜开。
  • 丰收在望，果农们笑逐颜开。

近义词

眉开眼笑喜笑颜开笑容可掬

反义词

愁眉苦脸忧心忡忡泣不成声
