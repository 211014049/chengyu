雪中送炭

xuě zhōng sòng tàn

品德成语 首字母 X
广告位 · 顶部

释义

在下雪天给人送炭取暖。比喻在别人急需时给以物质上或精神上的帮助。

出处 / 典故

出自宋代范成大《大雪送炭与芥隐》诗：「不是雪中须送炭，聊装风景要诗来。」炭，木炭。比喻在别人困难时给予及时的帮助。

例句 / 造句

  • 公司资金链紧张时，这笔投资真是雪中送炭。
  • 邻居在他生病时送来饭菜，雪中送炭暖人心。
  • 政策扶持对小微企业来说雪中送炭。

近义词

扶危济困济困扶危急人之难

反义词

雪上加霜落井下石乘人之危
